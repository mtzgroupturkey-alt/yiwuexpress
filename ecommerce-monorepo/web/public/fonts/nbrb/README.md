# NBRB Font Directory

Official Belarusian Ruble (BYN) font assets (such as nbrb.woff2, nbrb.woff, nbrb.ttf) can be placed in this directory if font files are provided.

The system natively renders the official NBRB approved Belarusian Ruble currency glyph using the SVG component (`@/components/icons/BynSymbol.tsx`) across all UI surfaces to guarantee pixel-perfect, cross-platform vector display with zero font-loading dependencies.
