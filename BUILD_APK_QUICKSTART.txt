MANUAL BUILD (if script doesn't work):
---------------------------------------
1. Install EAS CLI (one-time):
   npm install -g eas-cli

2. Navigate to mobile folder:
   cd c:\wamp64\www\yiwuexpress\ecommerce-monorepo\mobile

3. Login to Expo:
   eas login

4. Build APK:
   eas build --platform android --profile preview

5. Download when complete (link will be shown in terminal)
