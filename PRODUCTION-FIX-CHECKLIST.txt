COMMON ISSUES & FIXES

ISSUE 1: .env.production missing
---------------------------------
Fix:
  1. ssh -p 22 djdn@39.175.57.2
  2. cd /www/wwwroot/www.dromkok.com/web
  3. nano .env.production
  4. Add required variables (see EXECUTE-FIX-NOW.md)
  5. Save and exit
  6. pm2 restart dromkok-web
  7. Re-run: .\quick-fix-production.ps1

ISSUE 2: Database connection failed
------------------------------------
Fix:
  1. ssh -p 22 djdn@39.175.57.2
  2. sudo systemctl status postgresql
  3. If not running: sudo systemctl start postgresql
  4. Test: psql "postgresql://ecommerce:PASSWORD@localhost:5432/ecommerce" -c "\l"
  5. Re-run: .\quick-fix-production.ps1

ISSUE 3: Prisma Client error
-----------------------------
Fix:
  1. ssh -p 22 djdn@39.175.57.2
  2. cd /www/wwwroot/www.dromkok.com/web
  3. npx prisma generate
  4. npx prisma db push --accept-data-loss
  5. pm2 restart dromkok-web
  6. Re-run: .\quick-fix-production.ps1

ISSUE 4: PM2 not running
-------------------------
Fix:
  1. ssh -p 22 djdn@39.175.57.2
  2. pm2 list
  3. pm2 restart dromkok-web
  4. pm2 save
  5. pm2 logs dromkok-web --lines 50

ISSUE 5: Still getting 500 errors
----------------------------------
Check logs:
  ssh -p 22 djdn@39.175.57.2 'pm2 logs dromkok-web --err --lines 100'

Common error messages:
  "Cannot find module @prisma/client" → npm install @prisma/client
  "JWT_SECRET is not defined" → Add to .env.production
  "Database connection error" → Check DATABASE_URL
  "Invalid prisma invocation" → npx prisma db push
