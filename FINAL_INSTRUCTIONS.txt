================================================================================
DEPLOY TO PRODUCTION
================================================================================

Step 1: Deploy the code (removed broken page.tsx)
--------------------------------------------------------------------------------
SSH into your production server and run:

cd /root/ecommerce-monorepo/web
git pull origin production
npm run build
pm2 restart ecommerce-monorepo


Step 2: Add Nginx Redirect
--------------------------------------------------------------------------------
Run this ONE command on your production server:

sudo sed -i '/# Proxy Configuration for Next.js Application/i \    # Root Path Redirect\n    location = / {\n        return 307 /en/;\n    }\n' /etc/nginx/sites-available/dromkok.com && sudo nginx -t && sudo systemctl reload nginx


Step 3: Test
--------------------------------------------------------------------------------
Visit: http://dromkok.com
Should redirect to: http://dromkok.com/en/


================================================================================

cd /root/ecommerce-monorepo/web && git pull origin production && npm run build && pm2 restart ecommerce-monorepo && sleep 10 && sudo sed -i '/# Proxy Configuration for Next.js Application/i \    # Root Path Redirect\n    location = / {\n        return 307 /en/;\n    }\n' /etc/nginx/sites-available/dromkok.com && sudo nginx -t && sudo systemctl reload nginx && curl -I http://dromkok.com/
