================================================================================
NGINX REDIRECT: http://dromkok.com → http://dromkok.com/en
================================================================================

OPTION 1: Automatic Script (Easiest)
--------------------------------------------------------------------------------

1. SSH into your production server:
   ssh root@YOUR_SERVER_IP

2. Create the script:
   nano /root/nginx-redirect-setup.sh

3. Copy the content from nginx-redirect-setup.sh file and paste it

4. Make it executable and run:
   chmod +x /root/nginx-redirect-setup.sh
   bash /root/nginx-redirect-setup.sh

5. Done! Test: http://dromkok.com


================================================================================
OPTION 2: Manual Setup (3 Steps)
================================================================================

Step 1: SSH into your server
--------------------------------------------------------------------------------
ssh root@YOUR_SERVER_IP


Step 2: Edit Nginx Config
--------------------------------------------------------------------------------
sudo nano /etc/nginx/sites-available/dromkok.com

Find this section (around line 110):

    # ==========================================
    # Proxy Configuration for Next.js Application
    # ==========================================
    location / {
        proxy_pass http://localhost:3001;
        ...


Add THIS code BEFORE the "location / {" block:

    # ==========================================
    # Root Path Redirect
    # ==========================================
    location = / {
        return 307 /en/;
    }


So it looks like:

    # ==========================================
    # Root Path Redirect
    # ==========================================
    location = / {
        return 307 /en/;
    }

    # ==========================================
    # Proxy Configuration for Next.js Application
    # ==========================================
    location / {
        proxy_pass http://localhost:3001;
        ...


Save and exit:
- Press: Ctrl + X
- Press: Y
- Press: Enter


Step 3: Test and Reload Nginx
--------------------------------------------------------------------------------
# Test configuration
sudo nginx -t

# If test passes, reload nginx
sudo systemctl reload nginx


Step 4: Verify
--------------------------------------------------------------------------------
curl -I http://dromkok.com/

Should show:
  HTTP/1.1 307 Temporary Redirect
  Location: /en/


================================================================================

================================================================================
TROUBLESHOOTING
================================================================================

If nginx test fails:
--------------------------------------------------------------------------------
sudo nginx -t
# Look at the error message
# Usually it's a syntax error (missing semicolon, bracket)


Restore backup if needed:
--------------------------------------------------------------------------------
ls /etc/nginx/sites-available/dromkok.com.backup.*
sudo cp /etc/nginx/sites-available/dromkok.com.backup.* /etc/nginx/sites-available/dromkok.com
sudo systemctl reload nginx


Check nginx error logs:
--------------------------------------------------------------------------------
sudo tail -f /var/log/nginx/error.log


================================================================================
WHY THIS WORKS
================================================================================

This redirect happens at the NGINX level, which is:
✅ FASTEST - Before reaching Next.js
✅ SIMPLEST - Just one configuration change
✅ RELIABLE - Nginx handles it, not JavaScript
✅ SEO-FRIENDLY - Proper 307 redirect


================================================================================
WHAT HAPPENS
================================================================================

Before:
  User → http://dromkok.com → Next.js app → Loading... → ERRORS

After:
  User → http://dromkok.com → Nginx (307 redirect) → http://dromkok.com/en/ → SUCCESS
